# CORTEX Dictionary Lab

A corpus-driven dictionary editor built with Streamlit and DuckDB.

## Running

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

See [docs/USERS_MANUAL.md](docs/USERS_MANUAL.md) for usage.
